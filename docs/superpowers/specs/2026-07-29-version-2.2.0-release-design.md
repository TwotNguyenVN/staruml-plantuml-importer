# Design Spec: Version 2.2.0 Release Update

This specification outlines the process for updating the extension version of StarUML PlantUML Importer to `2.2.0` and releasing it.

## Proposed Changes

### Configuration Update
- Update `"version": "2.2.0"` in [package.json](../../package.json).

### Extension Installation
- Run `node manage.js install` to copy the files to the local StarUML extensions folder.

### Git Versioning
- Commit version bump change to git with message `chore: bump version to 2.2.0`.
- Push the commit to GitHub `main` branch.
- Create git tag `v2.2.0`.
- Push the git tag `v2.2.0` to remote origin.

## Verification Plan

### Manual Verification
- Verify that `package.json` is updated.
- Verify `node manage.js install` completes successfully.
- Verify git status, push status, and git tag creation.
